## About the Project

**TapalKala** is an e-commerce platform with customer-facing storefront pages and management interfaces.

My contribution focused on **web UI design and interface refinement**.

## My Contribution

- Storefront interface design
- Product and category page UI
- Shopping and commerce interfaces
- Dashboard UI
- Forms and account interfaces
- Responsive layouts
- Persian / RTL user experience
- Material-inspired visual components
- Visual consistency and interface refinement

## Focus Areas

| Area | Contribution |
|---|---|
| Storefront | Product-focused shopping interface |
| Product UI | Product and category presentation |
| Dashboard UI | Management and account interfaces |
| Responsive Design | Layout adaptation across screen sizes |
| RTL | Persian right-to-left interface design |
